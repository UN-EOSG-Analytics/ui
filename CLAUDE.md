

## Workspace Structure

In this VS Code workspace there are the following repos:

**External:**

- `transcripts/` –– [transcripts.un.org](https://transcripts.un.org/en) | UN Transcripts is a public preview tool that automatically generates transcripts from public United Nations meeting recordings
- `mandates/website/` [dev branch is the newest version] –– [mandates.un.org](https://mandates.un.org/) / mandates.un-two-zero.org | UN Mandate Source Registry
- `un80actions/` –– [un80actions.un.org](https://un80actions.un.org/) | This Dashboard complements the UN80 Initiative Action Plan. It provides a consolidated reference of the work packages across the three UN80 Initiative workstreams.
- `un-system-chart-navigator/` –– [systemchart.un.org](https://systemchart.un.org/) | The UN System Chart Navigator is an interactive way to explore the entities that make up the United Nations system
– `open/` –– open.un-two-zero.org | UN budgets overview transparency portal

**Internal:**

- `un-mandate-housekeeping/` –– [mandate-housekeeping.un-two-zero.org](https://mandate-housekeeping.un-two-zero.org/about/) | Streamline Your Mandate Citation Review / The Mandate Housekeeping Platform is being tested as a pilot tool to support UN Secretariat entities review and update mandate citations for the 2027 Proposed Programme Budget (PPB) – Programme Plan.
